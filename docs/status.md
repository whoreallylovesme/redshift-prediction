## 4. Определение «точной реализации» (договорились)

- **Уровень 1, побитовой** — недостижим (стохастичность); ближе всего был бы их `sdss.npz` (недоступен).
- **Уровень 2, процедурный** — всё написанное в статье реализовано так же; допустимые допущения (эпохи стадии 4.1 и т.п.) фиксируются здесь. ← текущая цель.
- **Уровень 3, проверка** — сверка наших предсказаний с их `z_pred.npz` на общих
  51,652 галактиках. **Только после неё имеем право сказать «реализовано верно».**
  (Требует инференс-CLI из §1.6.)
