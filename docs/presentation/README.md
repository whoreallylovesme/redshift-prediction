# Материалы презентации ВКР (Euclid Q1 photo-z)

Исходники и итоговые картинки всех схем/таблиц/графиков, использованных в презентации.
Компиляция TikZ: `tectonic <fig>.tex`; рендер PDF→PNG 300dpi (pymupdf).

## figs/
- `fig_pipeline_v6` — единая схема пайплайна стенда: Подготовка датасета → Обучение модели →
  Прогноз и метрики → Отчёты и графики → Сводный отчёт (full_report.html), артефакты под этапами.
- `fig_stack_v3` — схема стека: CapsNet + CatBoost + PHZ соседей → Стек CatBoost → z_phot.
- `fig_capsnet_v3` — схема CapsNet: Вход 64×64×4 → Свёртки → PrimaryCaps → DigitCaps (routing)
  → Голова MLP → ẑ; декодер — плашка снизу (только на обучении).
- `fig_gnn_v5` — схема GraphSAGE: Каталог 262k + метки SPE 31k → Граф соседей k=16 → SAGE×2 →
  Голова MLP → z_gnn; формула слоя — плашка снизу.
- `f1..f4` — формулы метрик (RMSE, доля выбросов η с определением Δz, σ_NMAD, bias), LaTeX-карточки.
- `fig_bins`, `fig_errdist` — анализ по бинам (гризм-тест, n=2429): NMAD/bias/доля выбросов по
  бинам z и квинтилям VIS-величины; распределение ошибок стека с модой/медианой/средним.
  Построены из ensemble_morph4/preds_test.parquet + edfn_labels.parquet (GPU-сервер).

## tables/
- `tbl_grism.html` — таблица «гризм-тест EDF-N (2 тестовых тайла)» в стиле стенд-отчётов
  (CSS из runs_srgz_fast/summary_table.html); скрин `tbl_grism.png` в презентации.

Правило из презентации: метрики/результаты экспериментов — скрины HTML-отчётов стенда;
сводные данные (таблица выборок Euclid) — нативная таблица Google Slides.
