# Photometric Redshift Prediction

Курсовая работа по предсказанию фотометрического красного смещения photoz.

## Шаг 1. Настройка окружения
Проект использует менеджер пакетов `uv`. Надо настроить окружение, для этого используется скрипт:
```bash
chmod +x set_uv.sh && ./set_uv.sh
```
Он автоматически подтянет все зависимости и настроит `pre-commit-hook`.
Хук использует линтер `ruff` и `mypy` для проверки типов. Актуальную конфигурацию, флаги можно найти в файлах `.pre-commit-config.yaml` и `pyproject.toml`. Есть скрипт `check_repo_code_style.sh` – он повторяет работу хука локально.


## Шаг 2. Пайплайн – принципы работы

В корне лежат четыре скрипта: `prepare_dataset.py`, `train.py`, `inference.py`, `visualize.py`.

Они делают ровно то, что написно в их названии, точнее:
- `prepare_dataset.py` – читает датасет из `csv` файла, чистит его и сохраняет тестовую и обучающие выборки на диск. Конфиг скрипта лежит в `configs/dataset.yaml`
- `train.py` – обучает модели и сохраняет `.pkl` на диск. Конфиги моделей лежат в папке `configs/`
- `inference.py` – применяет модели и сохраняет предикты на диск
- `visualize.py` – по полученным в предыдущем пункте предиктам, считает метрики, строит графики и сохраняет их в формате `.png` и `.html`

## Шаг 3. Пайплайн – запуск

Для удобства есть скрипт `run_fast_test.sh`, который прогоняет небольшую модель по пайплайну в целях проверки работоспособности. Для полного запуска, есть скрипт `run_all.sh`. Открыв эти скрипты можно посмотреть, какие параметры ожидают скрипты на вход.
