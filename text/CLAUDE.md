## Сборка

Документ требует **XeLaTeX или LuaLaTeX** (использует `fontspec` + `polyglossia` с русским Times New Roman, `pdflatex` не подойдёт):

```bash
# полный цикл с библиографией (нужен два прохода из-за \cite/\ref)
latexmk -xelatex -shell-escape coursework_photoz.tex

# или вручную
xelatex coursework_photoz.tex && xelatex coursework_photoz.tex
```

В `.venv` родителя TeX-движков нет — сборка делается системным TeX Live / MacTeX. Если в локальной среде нет xelatex, не пытайся собрать через `pdflatex` — сборка упадёт на `\setmainfont`.

## Стилевые соглашения текста

- Язык — русский, кавычки-«ёлочки», тире `—` (em-dash) вместо дефиса в перечислениях.
- Подписи: рисунки нумеруются как `Рисунок — N`, таблицы как `Таблица — N` (см. `\DeclareCaptionLabelSeparator{dash}` в преамбуле). Не меняй формат подписей без необходимости.
- Метаданные работы (`\worktitle`, `\studentname`, `\supervisor`, `\workyear`) задаются через `\newcommand` в преамбуле — правь там, а не в `\begin{titlepage}`.
- Полуторный интервал (`\onehalfspacing`), поля `30/15/20/20 мм` — фиксированы требованиями кафедры, не трогай без явной просьбы.

## Что НЕ делать

- Не создавай отдельные `.tex`-файлы под главы и не подключай их через `\input` — работа специально держится одним файлом.
- Не добавляй пакеты, требующие `pdflatex` (например, `cmap`, `pscyr`) — сломаешь XeLaTeX-сборку.
- Не редактируй PNG в `figures/` — они генерируются скриптами из родителя (`../python_sh/`, нотбуки в `../`); если нужно обновить рисунок, обнови источник, а потом перегенери.
