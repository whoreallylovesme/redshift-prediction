# Project: Photometric Redshift Prediction Coursework

This directory contains the LaTeX source and supporting materials for the coursework "Prediction of cosmological redshift using photometric features" (Прогноз космологического красного смещения по фотометрическим признакам) by E. E. Kadyrov (MSU CMC, 2026).

The text documents the experimental setup and results found in the parent directory.

## Project Overview

- **Subject:** Astrophysics, Machine Learning, Photometric Redshifts (photo-z).
- **Institution:** Moscow State University, Faculty of Computational Mathematics and Cybernetics (CMC), Department of Intelligent Information Technologies (ASVK).
- **Type:** Non-code project (Academic LaTeX documentation).

## Building the Document

The document uses modern LaTeX features (`fontspec`, `polyglossia`) and requires **XeLaTeX** or **LuaLaTeX**. It will not compile with `pdflatex`.

### Requirements
- TeX Live or MacTeX distribution.
- Fonts: Times New Roman, Courier New.

### Build Commands
```bash
# Recommended: Using latexmk for automatic multi-pass compilation
latexmk -xelatex -shell-escape coursework_photoz.tex

# Manual compilation (requires at least two passes for TOC and references)
xelatex coursework_photoz.tex
xelatex coursework_photoz.tex
```

## Key Files

- `coursework_photoz.tex`: The main and only LaTeX source file for the coursework.
- `figures/`: Directory containing PNG plots and diagrams. These are generated by scripts in the parent directory.
- `msu.jpg`: MSU logo used on the title page.
- `presa.md`: Contains the link to the Google Slides presentation for the work.
- `CLAUDE.md`: Specific guidance for Claude Code regarding this directory.
- `tit.txt`: An alternative title page for a related project (a co-author).
- `tmp.txt`: Notes from the supervisor regarding the experimental stand requirements (Transparency, Reproducibility, Extensibility, Efficiency).
- `Требования_..._ВКР_АСВК.DOC`: Official department requirements for thesis formatting.

## Development Conventions

### Academic Writing Style (Russian)
- **Language:** Russian (primary), English (secondary/citations).
- **Typography:** 
    - Use "ёлочки" quotes: «...».
    - Use em-dash (`—`) with spaces for list items and definitions.
    - Captions: `Рисунок — N` and `Таблица — N` (configured in preamble).
- **Formatting:** 
    - 1.5 line spacing (`\onehalfspacing`).
    - Margins: Left 30mm, Right 15mm, Top/Bottom 20mm.

### LaTeX Practices
- **Preamble Metadata:** Edit title, student name, and supervisor in the preamble via `\newcommand` (`\worktitle`, `\studentname`, etc.) rather than hardcoding in the `titlepage` environment.
- **Single File:** Keep the entire document in `coursework_photoz.tex`. Do not split into multiple files using `\input` or `\include`.
- **References:** Use actual experimental results from the parent project's `runs/` artifacts when updating tables.

## Constraints & Prohibitions

- **No pdflatex:** Never use packages or commands that break XeLaTeX compatibility (e.g., `cmap`, `pscyr`).
- **No Direct Image Edits:** Do not modify images in `figures/` directly. Update the source Python scripts/notebooks in the parent directory and regenerate them.
- **No Structural Changes:** Do not alter the departmental formatting (margins, spacing) without explicit instruction.
