# ИИ-агенты в работе

Код, эксперименты и отчёты готовились с ИИ-агентами по моим заданиям. Ниже — что использовалось и где лежат инструкции.

## Агенты

- **Claude Code** (настольное приложение) — основная линия: CLIP-предобучение, итоговая модель, сравнение с Phosphoros и PHZ Euclid, отчёты.
- **Codex** — проверки вариантов модели на полях F/S, журнал `docs/status.md`.
- **Kimi Code** — черновик месячного отчёта и скилл месячного отчёта.

## Инструкции агентам

- `CLAUDE.md`, `AGENTS.md`, `GEMINI.md` — правила проекта: команды, архитектура, GPU-сервер, ограничения.
- `text/CLAUDE.md`, `text/GEMINI.md` — правила для текста ВКР и презентации.
- `docs/experiment_setup.md` — постановка экспериментов: поля F/S для обучения, N — только тест.
- `docs/gpu_server_manifest.md` — правила работы на общем GPU-сервере.

Адрес сервера, порт и ключи в копиях для репозитория заменены заглушками `<gpu-host>`, `<port>`, `<ssh-key>`.

## Скиллы

- `ai/skills/make_report/` — отчёт по эксперименту в TeX: структура, стиль, проверка чисел.
- `ai/skills/make_monthly_report/` — месячный отчёт кафедре и календарный план; требования кафедры — в `CRITERIA.md`.

## MCP и плагины

- `telegram-readonly` — чтение чата с научными руководителями: требования к отчётам, замечания. Только чтение.
- `memory` — память проекта между сессиями.
- `jupyter` — интерактивные расчёты.
- Плагины Claude Code: `superpowers`, `feature-dev`, `context7`.

## Отчёты и метрики

- `reports/weekly/2026-11-06/` — недельный отчёт 6 ноября: TeX, PDF, рисунки, таблицы, `facts.json`, метрики `metrics/*.json`.
- `reports/monthly/2026-11-12/` — месячный отчёт за 13 октября – 12 ноября и календарный план.
