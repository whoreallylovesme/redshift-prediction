# Инструкции и skills агентов

## Единые правила

- `AGENTS.md` — основной файл правил проекта: команды, архитектура, стандарты кода, границы
  вычислений, GPU-сервер, публикация и тексты. `CLAUDE.md` содержит только `@AGENTS.md`; отдельных
  расходящихся копий для разных агентов нет.
- `docs/pipeline.md` — единый YAML, Prefect graph, preparation DAG, артефакты, MLflow и HTML.
- `docs/lightning.md` — границы `nn.Module`/`LightningModule`, веса и нейросетевые адаптеры.
- `docs/experiment_setup.md` — научный протокол и роли F/S/N.
- `docs/gpu_server_manifest.md` — ресурсы, серверный запуск и копирование результатов.

Адреса серверов, порты, ключи, токены и персональные данные в репозиторий не попадают.

## Skills репозитория

- `ai/skills/run_experiment/` — постановка и запуск научного эксперимента через единый Prefect-вход,
  серверные вычисления, приёмка и копирование артефактов.
- `ai/skills/make_report/` — TeX-отчёт по эксперименту: структура, стиль, источники чисел, графики и
  проверка перед сдачей. Шаблон — `template.tex` рядом со skill.
- `ai/skills/make_monthly_report/` — месячный отчёт кафедре и календарный план; требования —
  `CRITERIA.md`, шаблоны — `template.tex` и `plan_template.tex`.
- [research-slides-style](skills/research-slides-style/SKILL.md) — оформление научных
  презентаций и ретроспектив по завершённым отчётам.

Skill выбирается по задаче. Его инструкции не должны противоречить `AGENTS.md` и текущей схеме
pipeline; при изменении архитектуры связанные skills и документы обновляются в том же PR.

## Внешние интеграции

- `telegram-readonly` может использоваться для чтения требований научных руководителей и отправленных
  отчётов. Отправка сообщений не требуется. Если доступа нет, используются локальные источники с
  явным указанием этого ограничения.
- Дополнительные MCP, плагины агентов и memory не являются обязательными зависимостями репозитория,
  тестов или запуска эксперимента. Интерактивные вычисления не заменяют Prefect.

## Сохранённые отчёты

- `reports/weekly/2026-11-06/` — недельный отчёт: TeX, PDF, рисунки, таблицы, `facts.json` и метрики.
- `reports/monthly/2026-11-12/` — месячный отчёт и календарный план: TeX, PDF и таблицы.
